# Vedanshi Garg — 3D Portfolio

React + TypeScript + Vite portfolio built from the supplied resume and professional photo.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```

The original resume is included at `public/VedanshiGarg-Resume.pdf` and the supplied photo at `public/profile.jpg`.

Content is intentionally limited to information present in the supplied resume.
